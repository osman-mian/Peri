# Peri
Code for our AISTATS23 paper titled [Nothing but Regrets — Privacy-Preserving Federated Causal Discovery](https://proceedings.mlr.press/v206/mian23a.html)

> Tldr: We discover causal graphs in federated settings with privacy guarantees using nothing but a single number: regret.


Use **`main.py`** to see an example of how the code works.


## Required Packages
- ges
- cdt  
- rpy2 (to run the Multivariate Adaptive Regression Splines (MARS) that is used by GLOBE algorithm, if you simply want to use vanilla GES, this can be ignored)
